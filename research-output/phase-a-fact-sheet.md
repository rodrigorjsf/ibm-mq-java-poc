## Impact on the brief's premises

**P2 — `allclient 9.4.5.0` / Java 21:** NO CONTRADICTION. Both valid: `com.ibm.mq.allclient:9.4.5.0` is a real artifact (javax.jms, JMS 2.0), and Java 21 is supported on 9.4.x (Semeru 21 bundled). Caveats: 9.4.5.1 is the newest fixpack (9.4.5.0 resolves normally); the corresponding image tag is `9.4.5.0-r1/r2`, not bare `9.4.5.0`.

**P6 — Report constants / default COPY_MSG_ID / persistence:** PARTIALLY CONTRADICTED.
- Default `MQRO_COPY_MSG_ID_TO_CORREL_ID`: **CONFIRMED** (value 0, the assumed one).
- Persistence: **REFUTED** — reports **inherit** the persistence of the original; persistent original → persistent report. The belief that COA/COD are non-persistent by default is wrong.
- The "MQRO_* values from WMQConstants" framing: **CORRECTED** — MQRO_*/MQFB_* live in `com.ibm.mq.constants.CMQC`/`MQConstants`, not in `WMQConstants`.

**P10 — `pooled-jms` javax version:** NOT CONTRADICTED, but SUBOPTIMAL. "1.x = javax.jms" is correct, but **2.x is also javax** (latest 2.0.9) and is the maintained javax line recommended for a new project. Pinning 1.x leaves you on an older series, not a wrong one. (3.x = jakarta.jms.)

**Corretto 25 runtime (JDK certification / Security Manager):** VIABLE with caveats, and two of the brief's assumptions are REFUTED.
- "Java 25 not listed for 9.4.5": **REFUTED** — there is dedicated operational guidance in the 9.4.x docs.
- "allclient breaks on JDK 24/25 due to SecurityManager (JEP 486)": **REFUTED** — the SecurityManager is optional and not enabled by the samples/scripts.
- Real actions when running on Corretto 25: pass `--enable-native-access=ALL-UNNAMED` (native-access warning in `System.loadLibrary`) and **avoid TLS_RSA_* CipherSpecs** (disabled as of Java 25).
- The "8/11/17/21 certified" enumeration remains **not confirmable** by a primary source (SPCR report JS-rendered) — do not assert it as a hard fact.
